# Investor RPG — จากยาจกสู่นักลงทุน

เว็บแอปการเงินส่วนตัวในรูปแบบเกม RPG สไตล์ Retro OS มี 2 เมนูหลัก:

- **💰 รายรับ-รายจ่าย (ใช้ทุกวัน):** จดรายจ่าย วางแผนงบรายเดือน และดูสรุป โดย sync กับ Google Sheet ได้
- **⚔️ ลงทุน (สร้างพอร์ต):** ตัวละคร คลังสมบัติ แผนที่โลก เควสต์ บอส และราคาสด

ทั้งสองเมนูเชื่อมกัน: วินัยการจดบัญชีและงบ DCA จะกลายเป็นค่าสถานะ เควสต์ และบอสในเกม

รองรับภาษาไทย/อังกฤษ, โหมดมืด/สว่าง และมือถือ (ติดตั้งลงหน้าจอหลักแบบ PWA ได้)

รวมมาจาก 3 โปรเจค:
- **Investor RPG:** เกม พอร์ต เควสต์ บอส
- **โปรเจค 2 (รายรับรายจ่าย):** ย้ายฟังก์ชันทั้งหมดมาไว้ใน `src/money/` และใช้ Google Sheet + Apps Script ชุดเดิม
- **โปรเจค 3 (Portfolio Tracker):** นำโค้ดดึงราคากองทุนและคริปโตมารวมไว้ใน `server/`

> ⚠️ แอปนี้เป็นเครื่องมือช่วยสร้างวินัย ไม่ใช่คำแนะนำการลงทุน ตัวเลขจำลองไม่รับประกันผลตอบแทน

## เริ่มต้นใช้งาน

> จะเอาขึ้นเว็บให้ใช้บนมือถือ ดู [ติดตั้งขึ้น GitHub Pages](#ติดตั้งขึ้น-github-pages-ทีละขั้น) และ [ตั้งค่าเริ่มใช้งาน](#ตั้งค่าเริ่มใช้งาน)

**ง่ายที่สุด (Windows):** ดับเบิลคลิก `เปิดโปรแกรม.bat` จะเปิดเซิร์ฟเวอร์ราคาและแอปให้พร้อมกัน ครั้งแรกจะติดตั้งทุกอย่างให้เอง

ต้องมี Node.js 22 ขึ้นไป ส่วน Python 3.10 ขึ้นไปจำเป็นเฉพาะถ้าจะใช้เซิร์ฟเวอร์ราคาสด

```bash
npm install
npm run dev            # เปิด http://localhost:5173
npm run dev -- --host  # เปิดให้มือถือใน Wi-Fi เดียวกันเข้าได้
npm run build          # ตรวจ type แล้ว build ลงโฟลเดอร์ dist/
npm run preview        # ลองเปิดไฟล์ที่ build แล้ว
npm run check          # ทดสอบสูตรเกม + ปฏิทิน + ตรรกะรายรับรายจ่าย
```

### ลูกเล่นเกม (ได้ EXP / ทอง ฝั่งลงทุน)

| กลไก | กติกา | รางวัล |
|---|---|---|
| ❤️ HP ประจำวัน | HP = (งบทั้งเดือน − ที่ใช้ไปก่อนวันนี้) ÷ วันที่เหลือ · จดรายจ่าย = โดนโจมตี | จบวันโดย HP ไม่ติดลบ (และมีการจด/กดวันไม่ใช้เงิน) +20 EXP |
| 👾 ดันเจี้ยน | ทุกซองในแผน (ไม่รวมหนี้) คือมอนสเตอร์ ใช้ถึง 80% = คลั่ง เกิน 100% = ชนะเรา | จบเดือนโดยไม่มีซองไหนเกินและยอดรวมไม่เกินแผน +300 EXP |
| 🐉 มังกรหนี้ | HP = เงินต้นที่เหลือ · จ่าย 1 งวด = ฟัน 1 ครั้ง | งวดสุดท้าย +1,000 EXP |
| 🎁 หีบสมบัติ | เป้า 🎯 ของถังเงิน เปิดหีบทุก 25% | +50 EXP ต่อหีบ ใบสุดท้าย +200 |
| 🏅 เหรียญตรา | รายการแรก · ต่อเนื่อง 7/30 วัน · วันไม่ใช้เงิน · เคลียร์ดันเจี้ยน · ปลดหนี้ · ถึงเป้า | +200 EXP |
| 💰 ของดรอปวันเงินเดือน | จดรายรับแล้วมีเอฟเฟกต์ได้รับทอง พร้อมบอกงบลงทุนเดือนนี้ | เดือนละครั้ง +50 EXP (×3 ถ้าแผนมีถังลงทุน) |
| 📜 เควสต์ท้าทายประจำสัปดาห์ | สุ่มจากวันจันทร์ของสัปดาห์ (ทุกเครื่องได้เควสต์เดียวกัน): จด 5 วัน · ไม่ใช้เงิน 2 วัน · HP ไม่ติดลบ 4 วัน · ไม่มีกาแฟ/ชานม 3 วัน · ใช้ไม่เกิน 90% ของ HP ทั้งสัปดาห์ | +150 EXP (นับสัปดาห์นี้และสัปดาห์ก่อน) |
| 📖 บันทึกการต่อสู้ | สรุป 7 วันล่าสุดเป็นเรื่องเล่า: โดนโจมตีกี่ครั้ง ศัตรูหนักสุด วันดี/บาดเจ็บ มอนสเตอร์ที่คลั่ง | — |
| 🏪 ร้านค้า | ใช้ทองแลกฉายาและกรอบรูปตัวละคร (แสดงในข้อมูลตัวละคร) เป็นของตกแต่งเท่านั้น | ใช้ทอง |

- รางวัลคำนวณจากข้อมูลล้วน ๆ (`moneyRewards` ใน `src/money/logic.ts`) และจ่ายครั้งเดียวต่อรายการ (จำไว้ใน `claimed` ของข้อมูลเกม)
- ไม่มีรางวัลจากการใช้เงิน · "วันไม่ใช้เงิน" ที่มีรายจ่ายภายหลังจะไม่นับ
- วันไม่ใช้เงินเก็บเฉพาะในเครื่อง ไม่ส่งขึ้นชีต (อยู่ในไฟล์สำรอง JSON)

### เชื่อมกับเกมอย่างไร

| ข้อมูลรายรับ-รายจ่าย | กลายเป็นอะไรในเกม |
|---|---|
| รายรับตามแผนของเดือน | รายได้ต่อเดือน (ใช้คิด STR) |
| รายจ่ายจริงเฉลี่ย 3 เดือนล่าสุด | ค่าใช้จ่ายต่อเดือน (ใช้คิด STR และเป้า HP) |
| ถังที่ชื่อมีคำว่า ลงทุน / DCA / หุ้น / กองทุน / เกษียณ | งบ DCA = (รายรับ − รายจ่ายผูกพัน) × % ของถัง → MP และ HP ของบอส |
| มีรายการที่จดไว้วันนี้ | เควสต์ "บันทึกรายจ่ายประจำวัน" สำเร็จเอง |

### Sync กับ Google Sheet (Apps Script ของโปรเจค 2)

ใช้ชีตและ `Code.gs` เดิม **ไม่ต้องย้ายข้อมูล** แอปเดิมก็ยังใช้คู่กันได้

1. ไปที่ **รายรับ-รายจ่าย → ตั้งค่า**
2. ใส่ URL `/exec` กับ TOKEN ชุดเดียวกับแอปเดิม

การทำงาน:
- **เก็บในเครื่องก่อน (local-first):** ใช้งานได้แม้ออฟไลน์ แก้แล้วจะส่งขึ้นชีตหลังหยุดพิมพ์ 1.5 วินาที (action `save`)
- ดึงข้อมูลล่าสุดทุกครั้งที่เปิดแอปหรือสลับกลับมาที่แท็บ
- **เชื่อมครั้งแรก:** ข้อมูลในชีตเป็นหลัก รายการที่มีเฉพาะในเครื่องจะถูกเพิ่มเข้าไป ไม่มีอะไรถูกเขียนทับ
- **เครื่องที่ยังไม่เคยดึงข้อมูลจากชีต จะส่งข้อมูลขึ้นไม่ได้** เพื่อกันเครื่องใหม่ที่ว่างเปล่าล้างชีต
- TOKEN เก็บใน localStorage ของเครื่องนั้น และส่งไปที่ `script.google.com` เท่านั้น (แอปตรวจ URL ก่อนส่ง)
- ควรกด "สำรอง JSON" เก็บไว้ก่อนเชื่อมชีตครั้งแรก

| ส่วน | รายละเอียด |

| **จำลองดอกเบี้ยทบต้น** | เงินก้อน + DCA รายเดือน · กราฟมูลค่าและเลเวลในอนาคต · เตือนเมื่อตั้งผลตอบแทนสูงเกินจริง |

### หน้าหลักและตัวละคร

- เปิดแอปมาที่ **หน้าหลัก (ที่พักของฮีโร่)**: ช่องจดด่วนอยู่บนสุด · **การ์ดตัวละครใบเดียว**: ฮีโร่ในฉากพิกเซล (ปราสาท / ป่า / ภูเขา) + เลเวล/EXP/ทอง + 4 แถบหลัก (HP วันนี้ · MP งบ DCA · เควสต์สัปดาห์ · เงินสำรองฉุกเฉิน — แตะเพื่อไปยังหน้านั้น) + STR/DEF/INT วันต่อเนื่อง เหรียญตรา + แจ้งเตือนเมื่อมีเรื่องต้องสนใจ · ปุ่มลอย **🗺 เลือกโลก** มุมซ้ายล่างของฉาก เปิดป๊อปอัป **ลูกโลกพิกเซลแบ่งครึ่ง** (โลกพิกเซลที่หมุนช้า ๆ รอบละ 40 วินาที): ซ้าย (เขียว) = โลกรายรับ-รายจ่าย · ขวา (น้ำเงิน) = โลกการลงทุน แตะครึ่งไหนเข้าโลกนั้น (ปิดด้วย ✕ / Esc / แตะพื้นหลัง)
- **ท่าทางตามงบวันนี้:** ปกติยืนหายใจและกะพริบตา · HP วันนี้ต่ำกว่า 30% = เหนื่อย ตัวงอ เหงื่อตก · ใช้เกินงบวันนี้ = นั่งหมดแรงกับพื้น · เควสต์สัปดาห์สำเร็จ = กระโดดดีใจ (มีข้อความบอกสถานะที่มุมฉาก)
- **ท่าตามเหตุการณ์:** จดรายจ่ายบนหน้าหลัก = ฮีโร่โดนตี (สะดุ้ง กะพริบแดง) · กดประตูเข้าโลก = ฮีโร่เดินออกจากฉากก่อนเข้าโลก · บันทึก DCA ตีบอสวันเงินเดือนออก = ฮีโร่เหวี่ยงอาวุธใส่มังกร (ปราบแล้วจะดีใจ)
- ฮีโร่เริ่มจาก **ตัวเปล่า** (ชาย/หญิง) ปรับรูปลักษณ์ได้ฟรี: สีผิว ทรงผม สีผม หนวดเครา ฉากหลัง
- **อุปกรณ์ 5 ช่อง** (หัว · เสื้อ · กางเกงและรองเท้า · อาวุธ · มือซ้าย) ซื้อด้วยทองจากเควสต์ หรือปลดล็อกของในตำนานจากเหรียญตรา (มงกุฎ ← ถึงเป้าเก็บเงิน · เกราะดันเจี้ยน ← เคลียร์ดันเจี้ยน · ดาบสังหารมังกร ← ปลดหนี้ · คัมภีร์วินัย ← จดต่อเนื่อง 7 วัน · ตะเกียงโรงเตี๊ยม ← วันไม่ใช้เงิน) เป็นของตกแต่งเท่านั้น
- ร้านค้า (อุปกรณ์ ฉายา กรอบรูป) อยู่ในหน้าข้อมูลตัวละคร และลองสวมดูก่อนซื้อได้

### 🔔 เฝ้าดูสินทรัพย์ (แจ้งเตือนมูลค่า)

อยู่บนสุดของแท็บแผนที่ในโลกลงทุน และหน้าหลักจะขึ้นบรรทัด 🔔 เมื่อมีเรื่องระดับเตือน/อันตราย
เกณฑ์ต่างกันตามประเภท (`WATCH` ใน `src/lib/game.ts`) และคำแนะนำเขียนเฉพาะประเภทนั้น:

| ประเภท | ขยับในวัน (ราคาสด) | ต่ำกว่าทุน | กำไร | ไม่ได้อัปเดต |
|---|---|---|---|---|
| คริปโต | ±10% | −30% | +50% | 7 วัน |
| หุ้นรายตัว | ±5% | −20% | +30% | 14 วัน |
| หุ้นปันผล | ±5% | −20% | +30% | 30 วัน |
| Index ETF | ±3% | −10% (มองเป็นช่วง DCA) | +25% | 30 วัน |
| REIT | ±4% | −15% | +25% | 30 วัน |
| ทองคำ | ±2% | −10% | +15% (rebalance) | 14 วัน |
| ตราสารหนี้ | ±2% | −3% | — | 60 วัน |
| กองตลาดเงิน | ±1% | −0.5% (ผิดปกติ) | — | 90 วัน |

- **บริบทเพิ่ม:** เงินระยะสั้น (horizon = สั้น) อยู่ในคริปโต/หุ้น/REIT · หุ้นหรือคริปโตตัวเดียวเกิน 15% ของพอร์ต
- ลงลึกขึ้นอีกขั้น (เช่น ETF จาก −10% เป็น −20%) นับเป็นการแจ้งเตือนใหม่
- "ไม่ได้อัปเดต" นับจากวันซื้อ/ฝาก/แก้ไขล่าสุด และไม่นับสินทรัพย์ที่ผูกราคาสด

### อาชีพ (ลักษณะรายได้จริง) และยศ

| อาชีพ | ตรงกับใคร | เป้าเงินสำรอง (HP) | โบนัส |
|---|---|---|---|
| อัศวินเงินเดือน | พนักงานประจำ | 6 เดือน | รางวัลบอสวันเงินเดือนออก ×1.5 |
| นักล่าอิสระ | ฟรีแลนซ์ / รายได้ไม่แน่นอน | 9 เดือน | ของดรอปวันเงินเข้า ×2 |
| พ่อค้านักขาย | เซลส์ คอมมิชชัน โบนัส | 9 เดือน | หีบสมบัติ ×1.5 |
| ผู้พิทักษ์ครอบครัว | ดูแลพ่อแม่หรือลูก | 6 เดือน | มีประกันได้ DEF +40 (ปกติ +30) · เคลียร์ดันเจี้ยน ×1.5 |
| นักผจญภัยฝึกหัด | จบใหม่ / เริ่มทำงาน | 3 เดือน | เควสต์ความรู้ ×1.5 |

- **ยศ** ตามเลเวล: เด็กฝึกงาน (0) → Junior (5) → Senior (10) → หัวหน้าทีม (20) → ผู้จัดการ (30) → ผู้อำนวยการ (50)
- **อิสรภาพทางการเงิน:** เมื่อ 4% ต่อปีของความมั่งคั่งสุทธิ ≥ ค่าใช้จ่ายต่อเดือน ยศจะเปลี่ยนเป็น "อิสรภาพทางการเงิน" (มีแถบความคืบหน้า)
- **เควสต์รายปี:** เช็กลดหย่อนภาษี PVD · SSF · RMF · ประกัน ก่อน 31 ธ.ค. (+400 EXP)

### กฎจากคู่มือการลงทุน (`ความรู้การลงทุน/`)

- **เงินเย็นเท่านั้น:** เตือนเมื่อ HP ต่ำหรือมีหนี้ดอกเบี้ยสูง
- **สัดส่วนหุ้นไทย:ต่างประเทศตามเลเวล:** 80:20 (ต่ำกว่า Lv 10) → 70:30 (ต่ำกว่า Lv 20) → 60:40
- **หุ้นตัวเดียวไม่เกิน 15% ของพอร์ต:** ถ้าเกินจะติดป้ายเตือนและลด DEF (ไม่นับกองทุนดัชนี)
- **ผลตอบแทนเกิน 10% ต่อปีในตัวจำลอง:** เตือนเรื่องมิจฉาชีพ ให้ตรวจสอบกับ ก.ล.ต.

### สูตรหลัก

- **EXP** = เงินลงทุนรวม + EXP จากเควสต์/บอส (โบนัสตามอาชีพ)
- **Level** = `floor(sqrt(EXP / 1000))`
- **DEF** = การกระจายตัวข้ามดินแดน (สูงสุด 70) + ประกัน (30) − ถือหุ้นตัวเดียวเกิน 15% (15)

## ราคาสด (เซิร์ฟเวอร์ราคา `server/`)

เป็น Python (FastAPI) ที่คอยดึงราคา แล้วส่งให้หน้าเว็บแบบเรียลไทม์ผ่าน Server-Sent Events
key ทั้งหมดเก็บที่ `server/.env` ไม่ส่งไปที่หน้าเว็บ และเซิร์ฟเวอร์นี้**อ่านราคาอย่างเดียว ไม่ส่งคำสั่งซื้อขาย**

| ประเภท | รหัสที่ใช้ | แหล่งข้อมูล | ความเร็ว | ต้องมี key |
|---|---|---|---|---|
| หุ้นไทย | `SET:PTT` | Settrade Open API | **เรียลไทม์** | ใช่ (`SETTRADE_*`) |
| หุ้นไทย (สำรอง) | `SET:PTT` | Yahoo Finance (`PTT.BK`) | ดีเลย์ ~15 นาที | ไม่ |
| หุ้น/ETF ต่างประเทศ | `US:VOO` | Yahoo Finance × อัตรา USD/THB | ดีเลย์ | ไม่ |
| กองทุนรวมไทย | `FUND:M0234_2537` | API ของ ก.ล.ต. | วันละครั้ง | ใช่ (`SEC_API_KEY`, ฟรี) |
| คริปโต | `CRYPTO:bitcoin` | CoinGecko (บาท) | ~1 นาที | ไม่ |
| ทองคำแท่ง 96.5% | `GOLD` | ราคาประกาศสมาคมค้าทองคำ (ผ่าน api.chnwt.dev) | ตามรอบประกาศ | ไม่ |

- ถ้ายังไม่ได้ใส่ key ของ Settrade ราคาหุ้นไทยจะใช้ Yahoo Finance ให้ก่อน (ดีเลย์)
- ทองคำใช้**ราคารับซื้อ** (เงินที่จะได้จริงถ้าขาย) และอัปเดตเฉพาะตอนสมาคมประกาศราคาใหม่
- `api.chnwt.dev` ไม่ใช่เว็บทางการ ถ้าบริการนี้หยุด ให้เปลี่ยน `GOLD_URL` ใน `.env`
- Sandbox ของ Settrade เรียกได้จาก IP ในไทยเท่านั้น (ตั้งแต่ 16 ก.ย. 69) ควรรันเซิร์ฟเวอร์บนเครื่องที่บ้านหรือ VPS ในไทย
- **บน GitHub Pages เซิร์ฟเวอร์นี้ไม่ได้รันไปด้วย** ป้ายราคาสดจะขึ้นว่าออฟไลน์ และมูลค่าที่กรอกเองยังใช้ได้ตามปกติ

**ตั้งค่า:**

```bash
cd server
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # macOS/Linux ใช้ .venv/bin/python
copy .env.example .env                                     # แล้วใส่ key ที่มี (ไม่ใส่ก็ใช้ได้บางส่วน)
.venv/Scripts/python -m uvicorn app:app --port 8787
.venv/Scripts/python check.py                              # ทดสอบการแปลงข้อมูลราคา
```

**ใช้ในแอป:** ตอนเพิ่มหรือแก้ไขสินทรัพย์ ให้เลือก "ราคาสด" แล้วกรอกจำนวนหน่วยที่ถือ (หุ้น / หน่วยลงทุน / เหรียญ / บาททองคำ)
ถ้าเซิร์ฟเวอร์อยู่คนละเครื่อง ให้ตั้ง `VITE_PRICE_SERVER=http://<ip>:8787` ตอน build

### ☐ 1. เตรียมเครื่อง (ครั้งเดียว)

```bash
git config --global user.name "ชื่อของคุณ"
git config --global user.email "อีเมลที่ใช้กับ GitHub"
```

- ลอง `npm install` แล้ว `npm run check` และ `npm run build` ในเครื่องก่อน ถ้าผ่านที่นี่ บน GitHub ก็จะผ่าน

### ☐ 2. สร้าง repo บน GitHub

github.com → **New repository** → ตั้งชื่อ เช่น `investor-rpg`

- **ไม่ต้อง** ติ๊กสร้าง README / .gitignore / license (มีในโปรเจคแล้ว)

### ☐ 3. push โค้ดขึ้นไป (ครั้งแรก)

เปิด terminal ที่โฟลเดอร์โปรเจคนี้:

```bash
git init -b main
git add .
git status
```

**ตรวจรายการใน `git status` ก่อน commit เสมอ** ต้องไม่มีไฟล์เหล่านี้ (ถูก `.gitignore` กันไว้แล้ว):

```bash

git remote add origin https://github.com/<username>/investor-rpg.git
git push -u origin main
```

> ครั้งแรกที่ push จะมีหน้าต่างให้ login GitHub ใน browser — login ตรงนั้น ไม่ต้องใส่รหัสผ่านใน terminal

## ตั้งค่าเริ่มใช้งาน

### ☐ 1. เตรียม Google Sheet + Apps Script (ครั้งเดียว)

**ใช้ชีตเดิมของโปรเจค 2 อยู่แล้ว** → ข้ามไปข้อ 2 ได้เลย ใช้ URL `/exec` และ TOKEN ชุดเดิม

**เริ่มใหม่ทั้งหมด:**
1. สร้าง Google Sheet ใหม่ คัดลอก id จาก URL ช่วง `/d/<id>/edit`
2. ในชีต: **ส่วนขยาย → Apps Script** → วางเนื้อหา `Code.gs` (จากโปรเจค 2) ทับทั้งไฟล์ → แก้ `SHEET_ID` บรรทัดบนสุดเป็น id ของชีตนี้ → บันทึก
3. เลือกฟังก์ชัน **`setup`** → Run → อนุญาตสิทธิ์ → เปิด Execution log คัดลอก **TOKEN** เก็บไว้ในที่ปลอดภัย
4. **การทำให้ใช้งานได้ → ใหม่ → เว็บแอป** · ดำเนินการในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก URL ที่ลงท้าย `/exec` เปิดใน browser ต้องเห็น `{"ok":true,...}`

> ⚠️ อย่าใส่ TOKEN หรือ `Code.gs` ที่มี SHEET_ID จริงลงใน repo นี้ TOKEN กรอกในแอปเท่านั้น

### ☐ 2. เชื่อมแอปกับชีต

1. เปิดแอป → **รายรับ-รายจ่าย → ตั้งค่า**
2. ถ้ามีข้อมูลในเครื่องอยู่แล้ว กด **สำรอง** เก็บไฟล์ JSON ไว้ก่อน
3. ใส่ URL `/exec` และ TOKEN → แอปดึงข้อมูลจากชีตมารวม (ไม่มีอะไรถูกเขียนทับ)
4. ตั้ง **วันเงินเดือนออก** ในหน้าเดียวกัน (ค่าเริ่มต้น: วันทำงานสุดท้ายของเดือน)

ทำข้อ 3 กับ **ทุกเครื่อง** ที่ใช้ (มือถือ, คอม) — เครื่องที่ยังไม่เคยดึงจากชีตจะส่งข้อมูลขึ้นไม่ได้ กันเครื่องเปล่าล้างชีต

### ☐ 3. ตั้งตัวละครและแผนเดือนแรก

1. หน้าหลัก → แตะตัวละคร → เลือก **เพศ หน้าตา ฉาก** และ **อาชีพ** (ตามลักษณะรายได้จริง มีผลกับโบนัส)
2. **รายรับ-รายจ่าย → แผน** ใส่รายรับและงบรายจ่ายของเดือน → ได้ HP รายวัน
3. เริ่มจดจากช่องด้านบนสุดของหน้าหลัก เช่น `กาแฟ 60`
4. **ลงทุน → คลัง** เพิ่มเงินสำรองฉุกเฉินและสินทรัพย์ที่มี

### ⚠️ ย้ายจาก localhost ไป github.io

ข้อมูลใน browser แยกตามเว็บ สิ่งที่จดไว้ตอนรัน `localhost:5173` **จะไม่ตามไปที่ github.io เอง**
- **รายรับ-รายจ่าย:** ถ้าเชื่อมชีตแล้ว แค่เชื่อมชีตบน github.io ก็ได้ข้อมูลครบ ถ้ายังไม่เชื่อม → กด **สำรอง** บน localhost แล้ว **กู้คืน** บน github.io
- **ฝั่งลงทุน/ตัวละคร** (ของที่ซื้อ, หน้าตา, พอร์ต) ยังไม่มีปุ่มสำรอง ต้องตั้งใหม่บน github.io

เซิร์ฟเวอร์ราคา (`server/`) ไม่ได้ขึ้นไปกับ GitHub Pages ถ้าต้องการราคาสด ให้รันบนเครื่องที่บ้านหรือ VPS
แล้วตั้ง `VITE_PRICE_SERVER` ตอน build (ดูหัวข้อราคาสดด้านบน) — ถ้า GitHub Pages เป็น `https` เซิร์ฟเวอร์ต้องเป็น `https` ด้วย browser ถึงจะยอมเชื่อม

### แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| เปิดลิงก์แล้ว 404 | ยังไม่ตั้ง Pages Source เป็น GitHub Actions หรือ Actions ยังไม่เสร็จ |
| Actions ล้มที่ `npm run check` | สูตรในโค้ดผิด — รัน `npm run check` ในเครื่องดูข้อความ แก้แล้ว push ใหม่ |
| Actions ล้มที่ `npm ci` | `package-lock.json` ไม่ได้ push ขึ้นไป หรือไม่ตรงกับ `package.json` → รัน `npm install` แล้ว commit ไฟล์ lock |
| ตั้งค่าชีตแล้วขึ้น `unauthorized` | TOKEN ไม่ตรง หรือยังไม่ได้ Run `setup` — ข้อความในแอปจะบอกว่ากรณีไหน |
| เปิด URL `/exec` แล้วเจอหน้า login | ตอน deploy Apps Script ยังไม่ได้เลือก "ทุกคน" |
| แก้ `Code.gs` แล้วไม่มีผล | ต้อง **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL เดิมจึงจะใช้โค้ดใหม่ |

**เพิ่ม/แก้ข้อความ:** แก้ใน `src/lib/i18n.ts` เท่านั้น ถ้าฝั่งภาษาไทยขาด key จะ build ไม่ผ่าน

**ธีม Pixel RPG:** สีตาม design tokens ใน `พรอมพ์รูปแบบ Pixel art/` (โหมดมืด = กรมท่า `#0F1235`, โหมดสว่าง = กระดาษ parchment) สี `slate-*` ของ Tailwind ถูก remap ใน `index.css` และโหมดมืดประกาศตัวแปรชุดเดียวกันใหม่ใต้ `[data-theme="dark"]` · หัวข้อใช้ Pixelify Sans · **ตัวเลขใช้ DotGothic16** (โหลดเฉพาะตัวเลขและเครื่องหมาย + − % / : × ฿ $ ผ่าน `text=` ของ Google Fonts เพราะเลข 5/8 ของ Pixelify อ่านเหมือนตัว S) · ภาษาไทยใช้ Noto Sans Thai · ปิด faux-bold (`font-synthesis-weight: none`)

**Sprite:** ไอคอนพิกเซล 16×16 วาดเป็นตัวอักษรใน `src/lib/sprites.ts` (1 ตัวอักษร = 1 พิกเซล) แสดงผ่าน `<Sprite name size />` ใน `src/components/Sprite.tsx` ควรใช้ขนาดที่หารด้วย 16 ลงตัว `npm run check` ตรวจว่าทุก sprite เป็นตารางครบและใช้สีในพาเลทเท่านั้น

ตัวฮีโร่ (24×40) อุปกรณ์ และฉากหลัง (96×54) ไม่ได้วาดมือทีละพิกเซล แต่สร้างจากรูปทรงด้วยสคริปต์ Python (เติมขอบดำ 1px และเงาด้านขวา/ล่างให้อัตโนมัติ) แล้วเก็บผลเป็นข้อมูลใน `sprites.ts` (สคริปต์อยู่ที่ `tools/hero_gen.py` และ `tools/scene_gen.py` · รัน `python tools/hero_gen.py out.json` แล้วนำแต่ละแถวไปแทนใน `SPRITES`) · ผิวใช้ตัวอักษร `n/N` และผมใช้ `a/A` ซึ่งถูกเปลี่ยนสีตามรูปลักษณ์ตอนแสดงผล · ลูกโลกหน้าเลือกโลกสร้างจาก `tools/globe_gen.py` (แผนที่ 80×40 ต่อขอบซ้ายขวาได้ + แผ่นดิสก์ 40×40) รันแล้วเขียน `src/lib/globe.ts` ให้เอง เปลี่ยน `random.seed` เพื่อได้ทวีปแบบใหม่

**ท่าทาง/อนิเมชัน:** ไม่ได้เก็บภาพทีละเฟรม `poseRows()` ใน `sprites.ts` คำนวณเฟรมจากท่ายืนโดยเลื่อนส่วนของร่าง (หัว ลำตัว ขา) อุปกรณ์ทุกชิ้นจึงขยับตามเอง · `<Hero pose>` ซ้อนเฟรมเป็น `<g>` แล้วใช้ CSS keyframe (`show2/3/4`) สลับให้เห็นทีละเฟรม React ไม่ต้องวาดใหม่ทุกเฟรม และถ้าเครื่องตั้งค่าลดการเคลื่อนไหวจะเห็นแค่เฟรมแรก · เพิ่มท่าใหม่ได้ที่ `POSES`

## การเก็บข้อมูล (localStorage)

| key | เก็บอะไร |
|---|---|
| `investor-rpg:v1` | ข้อมูลเกมและพอร์ต (ยังอยู่เฉพาะในเครื่อง) |
| `investor-rpg:prefs` | ภาษา / ธีม |
| `investor-rpg:alerts.*` | การแจ้งเตือนที่ซ่อนไว้ / ที่ส่งเข้าเครื่องแล้ว |
| `investor-rpg:money` | รายรับรายจ่าย (sync กับชีตได้) |
| `investor-rpg:money.*` | สถานะ sync, ซองที่จำไว้, เป้าหมายเก็บเงิน, วันไม่ใช้เงิน, เดือนที่เลือก, URL/TOKEN ของชีต |

- ฝั่งรายรับรายจ่าย sync หลายเครื่องผ่าน Google Sheet ได้ ส่วนฝั่งพอร์ตยังอยู่เฉพาะในเครื่อง
- ล้างข้อมูล browser แล้วข้อมูลที่ยังไม่ได้ sync จะหาย ควรสำรอง JSON ไว้

## Tech stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · Framer Motion · Lucide icons · FastAPI (เซิร์ฟเวอร์ราคา) · Google Apps Script (ฐานข้อมูลชีต) · กราฟทุกตัววาดเองเป็นพิกเซล (`src/money/charts.tsx`: `PixelRing` วงแหวนพิกเซล, `BarsV`/`BarsH` แท่งมีขอบดำ + เงา `PX`; กราฟทบต้นเป็นแท่งรายปี แตะเพื่อดูปีนั้น)

## สิ่งที่ยังไม่มี / ไอเดียต่อไป

- เก็บข้อมูลพอร์ตและเกมลง Google Sheet ด้วย (ต้องเพิ่ม action ใน `Code.gs` แล้ว deploy ใหม่)

- ดึงพอร์ตจริงจาก Settrade (Get Portfolios / Get Trades) เข้าคลังสมบัติอัตโนมัติ
- แจ้งเตือนวัน DCA ผ่าน LINE Messaging API
- service worker สำหรับใช้งานออฟไลน์
- ฟิลด์ "อุตสาหกรรม" เพื่อเช็กการกระจายหุ้น 5–6 ตัวข้ามกลุ่มตามคู่มือ
